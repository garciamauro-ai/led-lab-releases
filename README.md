# LED Studio by MAVRO360

Planificador de pantallas LED para shows en vivo: pixel map, escenario 3D, curvatura, rig, luces y export a Resolume Arena (Advanced Output).

## Descargar

**[Última versión para Windows](https://github.com/garciamauro-ai/led-studio-releases/releases/latest)**: bajá `LED-Studio-Setup-x.y.z.exe` y hacé doble clic.

La primera vez Windows puede avisar que la app no es reconocida: **Más información → Ejecutar igual**.
Una vez instalada, la app se actualiza sola.

Este repositorio tiene solo los instaladores. El código es privado.
